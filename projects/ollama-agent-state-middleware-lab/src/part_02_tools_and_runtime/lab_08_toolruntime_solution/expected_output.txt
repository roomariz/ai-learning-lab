Conclusion
==========

ToolRuntime is the framework-native solution to Lab 07's manual passing:
- @tool decorator registers tools for the agent
- ToolRuntime is injected by the framework (not manually created)
- runtime.state reads current state, returns Command(update={...}) to write
- ToolMessage is required so the LLM knows the tool ran
- MemorySaver + thread_id persist state across invocations
- authorised_tools in state controls tool access at runtime

Key insight: This replaces the manual state-passing pattern from Lab 07.
