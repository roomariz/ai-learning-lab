Conclusion
==========

Tools read from and write to agent state using framework patterns:
- @tool decorator registers tools for the agent
- ToolRuntime is injected by the framework (not manually created)
- runtime.state accesses current state
- Command(update={...}) atomically updates state
- ToolMessage communicates results back to the agent
- MemorySaver and thread_id persist state across invocations

Key insight: The runtime parameter is HIDDEN from the LLM.
The framework automatically injects ToolRuntime when tools are called.
