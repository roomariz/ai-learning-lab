17 Tool Authorisation Middleware
================================

===========================

Scenario 2: blocked tool
========================
[authorisation middleware] blocked: Blocked: tool 'delete_all_notes' is not authorised.

RESULT:
Blocked: tool 'delete_all_notes' is not authorised.

NOTES:
['existing note', 'authorised tool executed']

Conclusion
==========

Tool authorisation middleware checks whether a tool is allowed before execution. Blocked tools never run.
