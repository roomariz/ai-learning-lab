Conclusion
==========

Production-ready agents need deterministic controls around the model.
This lab combined everything learned so far:
- AgentState for structured state
- create_agent for framework-native agent creation
- @tool decorator and ToolRuntime for tool registration
- Command(update={...}) for atomic state updates
- ToolMessage for tool result communication
- MemorySaver + thread_id for persistence
- RunnableConfig for invocation configuration

Production controls added:
- Input validation BEFORE agent invocation (deterministic, not prompt-only)
- Tool authorisation inside tools (runtime check)
- blocked_request_count, error_count, tool_call_count for observability
- Deterministic summary showing all production metrics

Middleware (Lab 13+) will add cross-cutting concerns.
