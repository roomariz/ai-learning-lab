Challenge summary
=================

SUMMARY:
Manual state passing creates repeated responsibilities:
1. Each tool must receive the state argument.
2. Each tool must remember to check authorisation.
3. Each tool must remember to update shared bookkeeping.
4. Each tool can accidentally mutate state in inconsistent ways.
5. As tools grow, this pattern becomes noisy and fragile.

Conclusion
==========

Manual state passing is useful for learning, but it does not scale well. The next lab introduces a runtime-style object so tools can access state through a cleaner interface.
