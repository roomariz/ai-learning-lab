# 01 Messages-Only Memory

## Goal

Show why message history alone is not reliable agent memory.

## Problem

A model does not have independent memory during a new call. It only knows what is included in the current input.

If the previous conversation is not passed again, the model may not know earlier user facts, preferences, or decisions.

## What this lab demonstrates

This lab runs two separate model calls:

1. The user tells the assistant a preference.
2. A fresh call asks the assistant to recall that preference without including the earlier message.

The second call should fail or produce an uncertain answer.

## Run

```bash
uv run python -m src.01_messages_only_memory.main
```

## Expected behaviour

The exact assistant wording may vary because the response is generated by the local Ollama model.

The important behaviour is:

1. In the first call, the assistant acknowledges that the user prefers Python.
2. In the second call, the assistant does not know the preference because the earlier message was not included.
3. This demonstrates that message history is not the same as durable agent memory.
